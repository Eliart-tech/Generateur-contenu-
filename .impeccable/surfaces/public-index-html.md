## Scope

Surface : l'application Amorce entière (public/index.html + app.js + style.css) — écrans Créer (brief → angles → bulletin de résultat), Radar, Historique, Réglages. Mode : Operate. Build : code-led.

## Audience et tâche

Créateurs / solopreneurs francophones, futurs abonnés SaaS. Tâche : idée → angle justifié par une tendance → script prêt à publier, avec un verdict de potentiel lisible en 3 secondes ; plus tard, saisir le relevé réel. Générations de 1 à 3 minutes : l'attente doit rester rassurante.

## Direction contract

THESIS : un score est une prévision — une bande de probabilité, un indice de confiance, puis le relevé réel qui la vérifie. Refuse le tableau de bord gris à jauge générique et l'esthétique « IA » (dégradés violets, étincelles).

OWN-WORLD : le bulletin météo. Shell bleu carte (#0C315C), fond ciel froid (#E8F0FA) le jour et nuit bleu profond la nuit ; l'échelle thermique code toute donnée de potentiel (froid bleu → tiède jaune → chaud orange → brûlant rouge) ; indice de confiance en 5 pastilles ; symbole cartographique du front chaud pour les tendances ; Fira Sans / Fira Sans Condensed, chiffres tabulaires.

STORY : le visiteur comprend qu'Amorce lit les tendances, croit au verdict parce qu'il voit pourquoi (facteurs, tendance, confiance), copie ou réécrit en un clic, puis revient saisir le relevé.

FIRST VIEWPORT : écran de résultat (cf. maquette bulletin) — barre latérale bleu carte ; en tête titre de l'idée + brief + étapes ; onglets plateformes à vignettes thermiques ; bande-bulletin pleine largeur (note-température 78, « Top 25 % de ta niche », phrase-verdict, échelle 4 segments, confiance, Prévu · Relevé) ; dessous script (gauche, le plus lisible) et facteurs + 3 améliorations + « Réécrire » (droite).

FORM : « Bulletin » — pick (rang 1 de ma liste ancrée, carte IMPECCABLE'S PICK), seed e90afa38.

FINISH : unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Moment mémorable

« Le bulletin tombe » : à l'arrivée de l'évaluation, l'aiguille de l'échelle glisse jusqu'à la bande et la température monte jusqu'à la note (une fois, réduit sans mouvement si prefers-reduced-motion).
